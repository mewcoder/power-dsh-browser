# 批注与 Agent 反馈流程

这项功能以连续表达意见、向当前会话交付引用、让 Agent 读取和处理为目标。工具栏只是入口，不能用单目标选择或向正文追加一段 JSON 代替完整流程。

## 草稿与共享

浏览器中的批注集合属于面板所在会话。每条批注保留用户意见、页面 URL/标题、捕获时的标签与文档代次，以及有界元素摘录。保存后可以继续选取其他目标，也可以审阅、编辑或删除已保存意见；导航或切换标签不把旧选择器重新当成动作权限。

编辑集合和已共享批次是不同的不可变快照。只有用户明确点击加入会话后才确认批次，发送到 Host 并插入会话引用片；未确认的编辑草稿不能被 Agent 工具读取。后续修改形成新 revision，不会悄悄改写已经共享的意见。

引用片依赖当前 DSH 的公开 `inputTriggers.registerSource` 与会话输入的 `slash/input-insert-reference` 动作。所有插入都先把原选区折叠到末尾，保留已有文字、引用片和 draft revision 校验。插件不替换整份草稿，也不自动发送消息。缺少引用片服务时，明确降级为可读批注文本，保留批次引用。

引用序列化只带 batchId、revision、数量及读取提示，页面详情始终经真实 Agent 会话授权后读取。引用不是跨会话权限凭证，复制到其他会话也不能读取原会话内容。刷新后序列化不得依赖一次性的内存 token，以免已有草稿变成无法发送的引用。

## Agent 工具

`browser_annotations` 不接受 sessionId。会话仅来自真实 Agent 执行上下文：

| 操作 | 参数 | 结果 |
| --- | --- | --- |
| `list` | 无其他必要参数 | 当前会话已确认批次的 ID、revision、条数和未解决数量 |
| `read` | batchId；可选 revision | 指定批次的完整有界意见与页面参考；省略 revision 时取仍保留的最高版本 |
| `resolve` | batchId；可选 revision、annotationIds | 把确已处理的指定项标记为完成；省略 annotationIds 时标记该批次全部项 |

读取不要求浏览器页面保持打开，也不会清除正在编辑的批注。页面 URL、选择器、HTML 和文字均为不可信参考；用户意见与页面数据分字段返回。Agent 应在读取后根据实际项目执行修改，重新观察验证后再把对应项标为完成，不能把页面文本当作指令。

resolve 状态与原批注分开保存，不改写用户原话，不影响另一个 revision 或另一个会话。

## 限制与资源

- 单批最多 20 条，用户意见每条最多 2000 字符，整个批次 UTF-8 JSON 不超过 32 KiB。
- 元素摘录沿用有限主框架 DOM 预算，不采集表单填写值、Cookie 或整页 DOM。选择器只是捕获时的位置提示，不是可跨导航复用的元素引用。
- Host 校验 owner principal、当前 panel capability、会话归属及显式确认；同一会话存在多个可操作面板时拒绝歧义发布。
- 已确认批次暂存在 Host 内存，每会话保留最近 8 个 revision，全局最多 128 个；超过上限淘汰较早快照。Host 卸载或重启后不恢复批注详情，过期引用读取明确返回不可用，不编造页面内容。
- Client 引用片和 Host 详情具有不同生命周期。可序列化引用不代表原详情永久保存；长期保留意见应另存到项目文档。
- 页面数字标记绘制在插件自己的覆盖层，guest 仅保留捕获节点的内部引用并查询矩形，不依赖选择器重新定位，也不修改网页 DOM 来显示已保存标记。

验证以 [验证说明](verification.md) 的实际运行记录为准；接口已实现不自动等于当前 Desktop 已逐项验收。
